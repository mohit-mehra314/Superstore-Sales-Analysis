# 🛒 Superstore Sales Data Analysis

## 📌 Project Overview

This project focuses on **analyzing, cleaning, and visualizing Superstore sales data** using Python and Jupyter Notebook.

The goal of this project is to explore sales performance, identify important business trends, understand customer and product performance, and present insights through meaningful visualizations.

---

## 🎯 Objectives

- Clean and prepare the raw sales dataset
- Perform **Exploratory Data Analysis (EDA)**
- Analyze sales and profit performance
- Identify top-performing products and categories
- Understand regional and customer-level sales trends
- Analyze sales over time
- Create visualizations to communicate business insights
- Generate data-driven conclusions

---

## 🛠️ Technologies & Tools

- **Python**
- **Jupyter Notebook**
- **Pandas** – Data cleaning and analysis
- **NumPy** – Numerical operations
- **Matplotlib** – Data visualization
- **Seaborn** – Statistical visualization

## ▶️ How to Run the Project
